# Segment Anything Model 

## Overview

SAM2 is a segmentation model developed by Meta that extends the capabilities of the original Segment Anything Model (SAM). It supports both image and video segmentation and can track objects across frames.

## Key Features

- Prompt-based segmentation
- Image segmentation
- Video segmentation
- Object tracking
- Memory-based architecture

## Applications

- Video editing
- Annotation tools
- Medical imaging
- Autonomous systems

## Demonstration

The notebook demonstrates mask generation using a pretrained Segment Anything Model (SAM). The SAM2 architecture and workflow were also explored as part of the study.

- Understood SAM2 architecture and capabilities
