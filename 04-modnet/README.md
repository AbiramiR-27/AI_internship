# MODNet

## Overview

MODNet (Matting Objective Decomposition Network) is a lightweight portrait matting model designed for accurate human segmentation and background removal.

Unlike general segmentation models, MODNet focuses specifically on extracting people from images while preserving fine details such as hair and object boundaries.

---

## Key Features

* Human portrait segmentation
* Real-time performance
* Background removal
* Fine boundary prediction
* Lightweight architecture

---

## Workflow

Input Image
↓
MODNet
↓
Alpha Matte / Segmentation Mask
↓
Foreground Extraction
↓
Background Removal
